# 乙方代理記憶（第一、二輪共 12 場後整理）

## 1. 打法要點（現行規則 v5，內容 builtin-18 之後）

### 規則重點
- 命中 = 60 + 機型瞄準 + 技能×4 − 目標迴避 − 目標技能×2 + 距離修正 ± 各種修正；超過 80 的部分只算一半。
- **靜止射擊是關鍵**：移動中命中常只有 40–55%，停在速度 0 時有 75–90%。射擊回合就 hover（懸停），移動和射擊分開做。
- v5 高打低：只要高 1 層以上，一律命中 +5，沒有傷害加成；目標比你高 2 層以上算半掩護。樓頂的價值主要剩下視野和遮蔽。
- 傷害相剋：化學能（火箭砲、垂直飛彈）剋複合裝甲（X-00、X-13）、怕陶瓷；能量（X-13 武器腕、光束步槍）剋陶瓷（X-04、X-07）；動能（肩砲、機槍）打複合只有 75%，打陶瓷沒有加減。
- 外露（部位耐久剩 1/3 以下）：被打中一律 +25%。重力圈裡腿全毀就不能移動也不能轉向，是最穩的擊墜目標；宇宙裡背包全毀幾乎不能機動。
- 斬首：旗艦 = 隊上最貴（同分取先排的）。旗艦絕不進任何敵機射線，S1-4、S1-6、S2-4 都輸在旗艦被打斷腿或背包後遭集火。
- X-00 已經沒有重型掛點；重型武器（肩砲、垂直飛彈、迫擊砲、ATGM、背掛光束砲）只能裝在 X-04、X-13、X-02、X-05。
- 干擾器只能裝 X-07（4 分、重量 3）。半徑 4 內的我方：被導引武器打時命中 −30，直射也拿不到標定的 +10。**圈內的我方標定機標定不了**。開著的干擾器在 12 格內會被看到（隕石群也藏不住）。
- 標定（mark）是一個行動，先於所有射擊結算；同回合隊友就能用垂直飛彈打，直射也 +10。標定不需要視線，隨機標 2 台正面 ±60° 內、感測距離內的敵機。標定只在標定機的感測距離內有效：X-07 是 14 格，X-04、X-13 只有 10 格。
- 垂直飛彈：下回合移動結束後才落下；落下那一刻要檢查標定，標定機被打壞、目標走出感測範圍都會落空，而且行動步驟裡補標也救不回來。落下時目標若在敵方干擾圈內，命中 −30（介面顯示的命中率是發射當下的數字）。彈藥 8 發等於 4 輪；最晚打完第 3 輪就開始回補給點（停在補給點上、速度 0，才能用 resupply 行動）。
- **被標定時的反制**：倒退或側移 1–2 格，走出敵方標定機的感測範圍，來襲飛彈就會落空（S2-5 成功兩次）。
- 隕石群（v5）：群內機體只看得到群外 8 格內；外面的敵機要在 4 格內才看得到群內的人；從群內射出 −20；在群內開火後，10 格內的敵機看得到你，持續到下回合結束。群內速度 3 以上會被碎石撞傷（S1-3 B3 因此陣亡），進出群一律速度 2 以下。一片群大約只放得下 3–4 台。
- 拆樓（v5）：化學能 ×2.5（火箭砲一發約 125）。每層 200，拆光一層後有 50% 機率連鎖倒塌，摔落每層 20 點、75% 打在腿上。兩台機體不要站同一棟樓。
- 流彈（v5）：散射武器（機槍、臂砲、迫擊砲）沒打中時，可能落到 1 格內的另一台敵機身上，所以不要擠成一團。
- 擦撞：相對速度 3 以下只會讓雙方停下。預檢擋住時可以加 "force":true；群內擁擠時常需要這樣做。
- 機體的速度一回合最多改變 2（X-04 從速度 3 不能直接 hover，要先 straight-S-1/2 減速）。
- 錨鉤：攀升可多爬 1 層，速度上限 +2。從地面能直接上 3 層；4 層要從 1–2 層的樓頂跳上去。
- 補給點在雙方後方（宇宙圖 A 方約在 (6,3)，B 方約在 (18,21)）。飛彈機開局就要排在補給點那一側。
- 固定部署：8 台時出生位會壓縮在 x=1~23；排在名單前面的在西側（A 方）或東側（B 方）。**干擾機要緊排在旗艦旁邊，標定機排在另一端**。
- 感測距離 10（X-07 是 14）。在後排樓頂、離敵超過 10 格，就什麼都看不到。

### 有效配置（v4/v5 實戰）
- 主力：X-13 王牌，雙肩砲（城市戰再加錨鉤）。內建武器腕是能量武器，剋陶瓷，也適合獵殺 X-07 標定機。
- 旗艦：X-04 王牌，雙肩砲加機槍（可再加火箭砲），軀幹 130，躲在建築後或群內，身邊跟著干擾機。
- 標定＋飛彈：X-07 徵招兵（標定器，可加機槍、錨鉤，8–9 分）躲在岩石或高樓後、離敵 11–14 格；X-04 徵招兵雙垂直飛彈（16–18 分，可加標定器當備用）躲在樓後或岩石後。飛彈命中不看駕駛技能，所以駕駛用徵招兵。
- 干擾機：X-07 徵招兵加電子干擾器（10 分），貼著旗艦和主力。
- 推薦清單在 logs/lg3-recommend.json（S2 版本）。宇宙 130 的勝方配置：X-04 旗艦、干擾機、三台 X-13、兩台垂直飛彈機、X-07 偵察機（S2-6 打出 60:0）。
- 王牌勝過數量（S1-5）。低價機只會送分，除非小規模時當 8 分誘餌。

### 時機清單
- T1–T3：主力低速進群，或成對上高樓；干擾機跟緊旗艦；偵察機往另一側找掩體。
- 接敵前先停穩；集火單一目標，優先順序：殘機、斷腿或斷背包的、對方標定機、對方旗艦。
- 受損機體在腿或背包斷掉前就退到掩體後；打不到時，用 hover 加 facingOffset 原地轉向。

## 2. 文字席位操作
- 等待輪次：`cd C:\claude_project\mech_wing_project && npm run seat-wait -- <room> <seat> <上一個 n>`（timeout 600000），輸出 PROMPT n=... 加上局面。
- 下指令：先寫 seat 資料夾的 orders.tmp，再 `mv` 成 orders.json。出現 ERROR 時要用新的 n 重送完整指令；在移動階段送行動（或反過來）會報錯並吃掉一個 n。
- 每份指令都要有 "note"（繁中 1–3 句）；遊戲結束後送 {"t":"note","text":...}。
- 好用的 helper（放在 seat 資料夾裡，用 bash 寫）：
  - send.sh N：從 stdin 讀 JSON，寫入 orders.tmp 後 mv，執行 seat-wait 存到 last.out，印出 PROMPT 行、最新一段結算（awk 擷取最後一個「--- 」到「=== 局面」之間）、擊墜分，以及過濾後的 view。
  - mv.sh N "note" id:maneuver[:climb|:off=deg]...：組 moves JSON，然後印出 `grep "→ p對方" view.txt | sort -u`（目前可射擊的估計）。
  - act.sh N "note" id:weapon:target[:also1,also2] 或 id:none：組 actions。**不支援 mark 和 resupply，這兩種要手寫 JSON**（我曾因此漏掉一回合補給和一次標定）。
  - hov.sh：全隊 hover。cyc.sh：hover 一回合後，自動讓主力打可見的優先目標、飛彈機打被標定的目標。
  - opts.sh：把每台的可用機動壓成一行，[C] 表示可以攀升，!bX 表示會撞到建築。
- 讀機動選項時要把「，攀升可上樓頂」替換掉，否則用 tr '；' 切割會亂掉。
- 要避免的錯誤：
  - 送錯階段：先 `cat prompt.json` 確認是 move 還是 action。
  - X-04 沒有 bank-3 之類的機動，送之前先看選項。
  - 用 seat-wait 的回傳判斷階段，不要猜。
  - 用 loop 自動跑時，要能在出現目標或 ERROR 時停下。
  - 開局 8 台時先檢查有沒有人出生在地圖外；那次是 bug，已修正，但看到「開出地圖」要立刻回報。

## 4. 陣營設定（角色扮演用）
**名稱：灰燼航道同盟（Ashlane Concord）**
- 教條：「先看見，再開火；不見之敵，不追。」重視偵察、陣地與耐心，寧可讓敵人走進火網，也不拿主力去換一台殘機。旗艦是同盟的「燈塔」，永遠在最暗處。
- 命名風格：機體以「燈」「渡」「錨」「燼」系列命名，例如 燈守（旗艦）、渡鴉（偵察）、錨砲（高樓砲手）、燼雨（垂直飛彈）、霧帷（干擾）。駕駛用兩字名加航道代號，例如「沈岸·L1」。
- 駕駛：
  - 沈岸（王牌）：旗艦駕駛，冷靜寡言，信條是「燈不能滅」，從不冒進。
  - 霍栖遲（王牌）：高樓砲手隊長，喜歡站最高的屋頂，一開口就是彈道與風向。
  - 葉潮生（王牌）：第二砲手，急性子，總想追殘機，需要隊長拉住。
  - 白鷺（老兵）：第三砲手，老派可靠，習慣成對作戰，從不單獨上樓。
  - 阿薊（徵招兵）：偵察機「渡鴉」的駕駛，膽小但眼力極好，最擅長躲在岩石後標定。
  - 鄔七（徵招兵）：飛彈機「燼雨」的駕駛，話多，數彈藥數得比誰都準，最先喊「要補給了」。
  - 檀音（徵招兵）：干擾機「霧帷」的駕駛，溫和，像影子一樣貼著旗艦。
  - 魯大錨（老兵）：誘餌兼備用機的駕駛，粗獷樂天，自稱「最便宜的英雄」。
