# 甲方代理人記憶（S1＋S2 共 12 場之後）

## 1. 打法要點（規則 v5）

### 目前生效的規則重點
- 命中 = 60 + 機型瞄準 + 技能×4 − 目標迴避 − 目標技能×2 ＋距離修正 ＋相對速度修正 ＋標定 +10 − 正面射界外 20 − 掩護；超過 80 的部分只算一半。
- v5 高度：只要比目標高 1 層以上就是固定 +5，沒有傷害加成；目標比你高 2 層以上時，算半掩護（−20）。
- v5 隕石群：
  - 群內的機體往外只看得到 8 格；攻方要進到 4 格內才看得到群內的機體。
  - 從群內開火，會對 10 格內的敵機暴露到下回合行動步驟結束。
  - 群內打出去、打進去都吃 −20。
  - 在群內速度 3 以上會撞石受傷。
- v5 拆樓：化學武器打建築 ×2.5（火箭砲每發約 125）；建築每層 200 耐久，打建築命中 +30；塌一層摔 20，有 50% 機率連鎖往下塌。
- v5 流彈：散射武器（機槍、臂部機砲、迫擊砲）沒打中時，可能打到目標 1 格內的「敵機」（傷害減半、不會爆擊）。
- X-00 沒有重掛點（不能掛肩砲）。肩砲平台改用 X-04（陶瓷、迴避 5、軀幹 130）或 X-13（複合、迴避 0、內建兩具能量武器腕 20×2、無手）。X-05 有 1 個重掛點。
- 剋性：陶瓷怕能量（武器腕、光束步槍 +25%）、擋化學（火箭砲 −25%）；複合怕化學；反射怕動能。
- 部位外露（剩三分之一以下）會吃 +25%。重力圈裡腿被打壞＝不能動；太空裡推進背包被打壞＝不能機動。這兩個部位就是命門。

### 時機與陷阱
- 停住射擊：動能 0 時沒有相對速度懲罰，命中可以多 20–30。射擊回合前一回合就要先停好；速度變化一回合最多 ±2（從前進 1 不能直接倒退 2）。
- 標定（mark）：
  - 掃描正面 ±60°、感測距離內的敵機，不需要視線，隨機標兩台。
  - 標定在行動步驟中最先結算，同一步的直射就能吃到 +10。
  - X-07 感測 14，X-04、X-00 只有 10。X-07 標定機要放在高樓或岩石後面。
  - 標定機站在自家干擾機 4 格以內（剛好 4 格也算）就標定不了。這是最常犯的錯，開局就要拉開。
- 垂直飛彈：
  - 這回合發射，下回合移動結束後才落下；落地時目標必須還被標定，否則落空。
  - 被標定時，往標定機感測範圍外退一兩格，整波飛彈就會落空（S2-3、S2-5 都成功過）。地圖邊緣退不了，要先留好退路。
  - 每具莢艙 8 發，一輪用 2 發，所以只能打 4 輪。第 3 輪後就去補給（要停在自己的補給點上、動能 0，再下 resupply 指令）。
  - 垂直飛彈越頂，不吃掩護和高度，但吃干擾 −30。
- 干擾器（ecm_pod，只有 X-07 能裝）：
  - 半徑 4 內的我方機體被導引武器攻擊時命中 −30，直射也拿不到標定加成；但仍然標得到。
  - 開著的干擾機在 12 格內會暴露位置。
  - 一定要貼著旗艦（出場序就排在旗艦旁邊）。
- 打掉標定器（耐久 20）：對方在飛的飛彈會失去導引。能量武器、光束步槍是首選。
- 碰撞預檢：隊形太擠時指令會被拒絕。可以改走別的機動，或在指令加 "force":true（低速擦撞只是雙方停下）。
- 出場格位是固定的，依名單順序排開。旗艦與干擾機要相鄰；標定機、飛彈機排在另一端（S2-4、S2-6 都因為排錯浪費了好幾回合）。
- 不要讓單機停在敵方主力射程的邊緣、或停在空地上被集火；主力要成對同步移動。
- 旗艦絕不穿越開闊地，也不追擊；收拾殘血機交給非旗艦的機體。

### 有效的配置（v4 實戰結果；v5 之後，高樓的價值主要在視野和半掩護）
- 主力：X-13 王牌＋雙肩砲（城市再加錨鉤），20–21 分。X-04 王牌＋雙肩砲＋光束步槍或機槍當旗艦（軀幹 130）。
- 支援：
  - X-07 徵招兵＋標定器（＋機槍、錨鉤），8–9 分。
  - X-04 徵招兵＋雙垂直飛彈（＋標定器），16–18 分。
  - X-07 徵招兵＋干擾器，10–11 分。
- 城市：三台 X-13 成對佔中央 3 層以上的樓頂；旗艦躲在建築後面、干擾機同行；標定機站高樓；飛彈機躲在樓後。
- 太空：主力先低速（≤2）進隕石群、停住、待在干擾圈內；標定機從側翼岩石後面推進；飛彈機排在靠近補給點的一側。v5 下群內視野只有 8 格，開火又會暴露，據守不再無敵，記得用標定替全隊開視野。
- 擊墜門檻：盡量讓單機費用低於「門檻的一半」，讓對方必須擊墜三台以上。

## 2. 文字席位操作
- 等待：`cd C:\claude_project\mech_wing_project && timeout 600 npm run seat-wait -- <room> <seat> <n>`。n 傳最新看過的 PROMPT 編號；TIMEOUT 就用同一個 n 重跑。
- 下指令：先寫 seat 資料夾裡的 orders.tmp，再 `mv orders.tmp orders.json`。每份指令都要加 note（繁中 1–3 句）；所有存活機體都要有指令。
- 階段：沒有指令可下的步驟會被自動跳過；行動步驟即使沒有目標也會出現。一定要看 PROMPT 行的 phase=，不能假設移動、行動一定交替。
- 輔助腳本（放在自己的 seat 資料夾，用 bash 寫）：
  - go.sh n：如果有 orders.tmp 就 mv 成 orders.json，然後迴圈 seat-wait 直到拿到 PROMPT，結果存成 last.txt。
  - show 或 tick：印出 PROMPT、最近的結算、我方位置、「→ 敵方id」的命中估計、可見的敵機。
  - none.sh：對所有存活機體送 {"type":"none"}。hold.sh：所有存活機體送 hover-S-0。
  - loop.sh：沒有接觸時自動輪流送 hold 和 none，一旦出現目標或「發射垂直」就停下。
  - pat.sh：每台機體自動對估計清單裡第一個目標全武器開火。
  - 陷阱：tick、loop 只檢查「→ 敵方」，看不到 mark 行動的機會，會把標定的回合跳掉。有標定機時要手動下 mark。
- 查詢機動：`grep -A12 "^p1u0 " last.txt | grep -A1 可用機動 | tr '；' '\n'`。
- facingOffset：正數＝右轉＝角度增加；L 機動讓角度變小、R 機動讓角度變大。
- 我的機體編號：A 方是 p0uN，B 方是 p1uN；裝備 id 是 <unit>e<k>（看 view 的裝備列）。
- 錯誤處理：ERROR 會吃掉 orders.json，要重寫完整指令再送。遇到「沒有機動 X」就換一個清單裡有的機動。
- 遇到明顯的 bug（例如出生在地圖外）就停下、回報協調者，不要硬打。

## 4. 陣營設定（角色扮演用）
陣營名稱：**鐵穹巡禮團（Iron Vault Pilgrims）**
信條：先占高地、後發制人。我們不追逐，而是等待。槍聲之前先有標定，衝鋒之前先有撤退路線；每一台機體都要能活著回到補給點。
命名風格：
- 機體以「天文／鐘塔」命名，例如「晨鐘一號」「北辰」「渾天儀」。
- 駕駛使用雙字代號加職稱，例如「觀星手 霜燈」。
駕駛名冊：
- 霜燈（王牌，旗艦長）：冷靜到近乎冷漠，從不離開干擾圈，口頭禪是「讓他們先開火」。
- 鐵鷂（王牌，X-13 砲手）：屋頂上的狙擊狂，數到三才扣扳機，討厭移動中射擊。
- 白漏（王牌，X-13 砲手）：急性子，總想追殘血機，常被霜燈罵回來。
- 琉璃（老兵，X-07 標定手）：話少眼尖，習慣躲在岩石後，堅持和干擾機保持五格距離。
- 墨笛（徵招兵，干擾機駕駛）：膽小但忠心，一步不離旗艦，被稱為「影子」。
- 穀雨（徵招兵，垂直飛彈手）：算彈數的會計型，第三輪一打完就回補給點。
- 斑鳩（徵招兵，誘餌、X-00）：愛開玩笑，自願當活靶，說「我只值八分」。
- 青銅（老兵，X-04 拆樓手）：喜歡把對方腳下的樓打塌，嘴邊常掛著「地基最誠實」。
